# Shutdown reply omitted discarded edits and directed callers past a waiting save prompt — **CLOSED** (#4079, 2026-11-16)

Symptom: measured on Windows in [#4079](https://github.com/hexide-io/HexIDE/issues/4079), `shutdown_ide {}` discarded Form1's unsaved changes without naming them. `shutdown_ide {"force": false}` returned the same instruction to poll `/health`, while a save-changes prompt listing Project1 and Form1 waited indefinitely.

Workaround: before forced shutdown, inspect `get_document_tabs {}` for `isModified`. For non-forced shutdown, use `dump_visual_tree {window: "auto"}` and `interact` on Yes, No or Cancel; Cancel keeps the IDE running.

Fix: the reply captures unsaved project, form and module names on the UI thread after applying editor buffers and before shutdown preparation. Forced shutdown returns `discardedDocuments`, empty when nothing was modified, and explains the discard. Non-forced shutdown with unsaved work names it and directs callers to the waiting prompt instead of `/health`. The main window still closes only after the HTTP response completes (#644).
