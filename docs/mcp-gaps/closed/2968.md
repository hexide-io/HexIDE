# External Run To Cursor lacks a one-shot breakpoint route — **CLOSED** (#4045, 2026-11-16)

**Symptom.** Read from source at `45c900eee`, not measured live. During an external debug session, `step_into`,
`step_over`, `step_out`, `continue_program`, `break_program`, `run_to_cursor` and `set_next_statement` each reply
`{"success":false,"error":"This command is not available for an external debug session."}`. The Debug menu sends the
same commands to the adapter: `stepIn`, `next`, `stepOut`, `continue` and `pause`. With #2964 it also sends
`gotoTargets` and then `goto`. `stop_project` and `get_debug_state` already work in an external session.

**Workaround (reasoned, not checked).** Drive the Debug menu with `interact`. For Set Next Statement, place the caret first with
`open_file(name, line)`. Then read where the session stopped with `get_debug_state`.

**Suggested fix.** Route each tool to the external session as `ProjectRunnerService` routes the menu. Wait for the
adapter's next `stopped` event, and report the top frame's file and line, as `get_debug_state` reads them. #2968 has
the details, including the module-name-to-path mapping a line-taking tool needs.

**Implementation (#2968).** Steps, Continue and Break now use the menu routes and wait for a
new stopped stack before reporting its top source frame, running or ended. Set Next Statement
uses the supported goto route and resolves the module name to its saved file path. Adapter
refusals include their message and whether stopped inspection was kept. Covered headlessly
against the fixture adapter. The [live review](https://github.com/hexide-io/HexIDE/pull/2991#issuecomment-6605000192)
verified Step Over, Set Next Statement, Continue and Break against RDCore `84278ae` on
2026-11-03; Step Into, Step Out and adapter refusals were not exercised live.

**Fix (#4045).** Run To Cursor from a stopped external session uses the saved source's user
breakpoints and conditions plus a temporary cursor breakpoint. Unverified or moved targets are
refused without continuing. The next stop, End or a request failure restores the user set; a
session that ends takes the temporary line with it, so nothing is sent. If the adapter refuses the
restore, the reply says so and names the line where it may stop again, and the session is kept.
The restore never holds up the reader of the adapter's events, whose queue is bounded.
The menu and tool share the route. The tool reports the actual top source frame, running or ended,
and identifies a stop before the cursor target. Fixture adapter tests cover reaching the target,
a user breakpoint first, termination, unverified and relocated targets, continue refusal, conditions
and the menu item's IsEnabled.
