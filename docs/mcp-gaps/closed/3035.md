# Immediate inspection kept the oldest output — **CLOSED** (#3035, 2026-11-05)

Symptom: during the Windows live check of #3027 (2026-11-04),
`inspect_element(target: "Window/Custom[MainView]/Pane[DockControl]/Pane[Root dock]/List[PART_ItemsControl]/List[#0]/TitleBar[Immediate]/Pane[Immediate]/Custom/None[Immediate.Editor]", window: "ide")`
returned the first 4,000 of 17,492 characters, while `run_project` kept the last 4,000. Inspecting the owner
at `…/Pane[Immediate]/Custom` likewise kept only the first 200 in `Document`.

Workaround: use `run_project`'s `printed` during a run. To read all the existing buffer, copy the displayed
text; `inspect_element` has no paging.

Suggested fix: keep the end of output buffers and explain the dropped end in the reply.
