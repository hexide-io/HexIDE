# Dialog notes list spinner arrows as answers

**Symptom.** Project Properties' dialog note included template buttons alongside OK, Cancel and Help
(#3671, addressed with #3832). The supplied #3832 brief records the diagnosis but does not include
#3671's exact originating call or arguments; these still need to be supplied by the supervisor.

**Workaround.** Discover the dialog with `dump_visual_tree` and address its answer buttons directly.

**Fix.** `OpenDialogs.DescriptionOf` excludes repeat buttons, toggle buttons and buttons belonging to
another control's template. The shared automation styles also name menu scroll and spinner arrows.
English and German headless tests exercise Project Properties' description and arrow names.
Live verification remains with the supervisor.
