# Debug inspection tools refused external sessions — **CLOSED** (#4305, 2026-11-16)

**Symptom.** Measured on Windows in [#4305](https://github.com/hexide-io/HexIDE/issues/4305):
`get_call_stack {}`, `get_locals {}` and `evaluate {"expression":"i"}` refused a stopped RDCore
session with “This command is not available for an external debug session.” The IDE windows showed
Main at line 10 and i = 10000 (Long). Code inspection found the same refusal in watch and breakpoint tools.

**Workaround.** Use the IDE's Call Stack, Locals, Immediate and Watch windows, and its breakpoint menu commands.

**Fix.** The tools now use ExternalDebugService's frames, variables, REPL and watch evaluation,
and the Watch window's external store. Breakpoint replacement and Clear All use the editor's external
set and await adapter replies, and `get_breakpoints` reads that set; notes report verified, moved, unverified or refused entries and conditions
an adapter cannot honour. Running inspection explains `break_program` or stopping at a breakpoint.
External replies omit unavailable project/source fields and explain the adapter frame context.
Linux tests drive HexIDE.Dap.TestAdapter and inspect captured setBreakpoints lines and conditions.
The supervising session still needs to live-check RDCore; no new live measurement is claimed here.
