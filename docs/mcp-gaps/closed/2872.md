# `set_control_property` could not clear a picture — **CLOSED** (#2872, 2026-11-09)

**Symptom (2026-11-02, Windows, #2650's live check).** `set_control_property(formName: "Form1", controlName: "Picture1", property: "Picture", value: "(None)")` replied `"Cannot set 'Picture' to '(None)': it takes no text: use the picture row's ... button in the Properties window; answer_next_file_dialog can answer its file picker"`. The button it points to only loads, so a picture put on by mistake stayed until the control was deleted, and "clearing the picture keeps the size" couldn't be reached live.

**Workaround.** Delete the control and add it again.

**Fixed (#2872, the automation half).** `(None)`, the text `get_form_controls` shows for a row with no picture, clears `Picture`, `Icon`, `MouseIcon` and `DragIcon`, without regard to case. No other text reads as a picture, and the refusal now says so. Guarded by `None_clears_a_picture_and_no_other_text_reads_as_one` in `PropertyTextTests`.

**Still open on #2872:** clearing from the Properties window itself, which needs vb6.exe measured first, and the second "Invalid property value" box.
