## More arcs and sectors, and their fills, pixel by pixel (2026-11-19, #4771, SP6)

**The question.** [The circles page](circles-arcs-sectors-and-thick-pens-pixel-by-pixel.md) holds five arc and sector
grids at DrawWidth 1, and no rule tried on them reproduced all five. Five grids can't tell close candidates apart, so
which pixels do more arcs and sectors light, at other angles, radii and an aspect? And does `FillStyle` fill an arc or
a sector?

**The probe:** the circles page's, unchanged:
- **The form:** 120 by 120 pixels, `ScaleMode` 3 and `AutoRedraw` True, run in session 0 as a made exe. p-code and
  native code logged the same grids.
- **Each case:** it set `DrawWidth = 1`, `FillStyle = 1` (transparent) and `FillColor = 0`, then ran `Cls`. It drew
  once, in the default ForeColor unless a colour is named. Then it read every pixel of x and y 14 to 66 with `Point`.
- **The grids:** `#` is any pixel that isn't the background read at (2, 2) after the `Cls`; `R` is red and `G` is
  green. Each row starts at x 14, and only rows with something drawn are shown.

### What the grids show

- **CurrentX and CurrentY end at the centre** for all seventeen, as on the circles page.
- **An arc isn't the full circle's pixels cut to its angles.** Start 0 and end 0 drew a closed ring of 56 pixels.
  The plain r10 circle on the circles page also lights 56, but this ring has (49, 35) where the circle has (48, 35).
  The circles page's arc from 0 to 1.5708 has (49, 35) too.
- **An arc that starts at 0 leaves out the circle's pixel at angle 0.** From 0 to 1.5708 it lit no (50, 40) at r10
  (the circles page) and no (60, 40) at r20 (below). Start 0 and end 0 did light (50, 40).
- **A short arc can be one pixel.** From 1 to 1.2 radians at r10, it lit (44, 31) only.
- **`FillStyle` 0 fills a sector and not an arc.**
  - **The filled sector,** from -0.0001 to -1.5708 in red with FillColor green: red on exactly the 34 pixels the
    unfilled sector lights on the circles page, and green on 61 pixels inside it.
  - **The filled arc,** from 0 to 1.5708: red on exactly the 14 pixels of the unfilled arc on the circles page, and no
    green anywhere.
- **The ends of arcs and radii still follow no rule defended here.** The grids are the record.
