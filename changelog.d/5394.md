### Added

- **`IHexIdeHost.RegisterLanguagePacks` lets an add-in HexIDE grants it to add language packs for text it owns** (#5394).
  - **Where:** they come from the add-in's own assembly, in the IDE's pack format, and the IDE reads them in every layer it reads its own.
  - **Who:** it's deny by default, admitting only `Str.*` keys in the families the owner's grant names.
  - **Refused:** a key the IDE or another add-in holds, and a translation whose placeholders differ. Every key is checked before anything
    merges, and one refused key refuses the whole folder.
  - **Coverage:** the Translation Editor, Pseudo and the user's own translations cover the packs too. They're the home the Basic
    provider's strings move into (#5395).

### Fixed

- **A translation of a key the IDE doesn't hold at the time is no longer lost when the language's translations are saved** (#5394).
  - **Before:** the user's translations dropped such a key when they loaded, and the next save of that language wrote the file without it.
  - **Now:** it's kept and saved with the rest, and applies once something that holds the key is registered. Clearing a language's last
    translation, or resetting it, leaves a file that still holds kept ones.
