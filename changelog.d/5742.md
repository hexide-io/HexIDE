### Added

- **A container's class can give the form designer its pages** (#5742). `IDesignerPages` loads and records which page each child is on, shows the page under a click or the one asked for, and says how many there are and whether they can be switched. The Basic provider's SSTab answers through it, so the form designer and automation no longer name SSTab's class, and its pages work as before. Only a container's class is asked. A class that throws is logged, and that call answers as a container without pages would. Automation refuses a page switch the class can't check, and doesn't save one it fails.
