### Changed

- **The macOS app menu now groups About, Settings… and Quit** (#5383). Command+Comma opens Settings,
  Command+Q follows the IDE's save-on-close flow, and Option+Command+H hides other apps. On a Mac,
  File, Tools and Help no longer repeat Exit, Options and About.
- **Complete Word uses Control+Space on macOS**, in place of Command+Space, which is Spotlight's
  (#5383). macOS also keeps Control+Space for "Select the previous input source", and that shortcut
  is on by default. To use the key, turn it off in System Settings > Keyboard > Keyboard Shortcuts >
  Input Sources; Edit > Complete Word works either way.
