### Security

- **A language server entry that only connects is announced, as a new command is** (#5465). Before, an entry in
  `lsp-servers.json` with no `command` and a `tcp` or `websocket` `connect` endpoint was never announced. Anything
  able to write that file could make HexIDE dial any host, another machine included, and send it the project's
  folder (a path under the user's profile) in `initialize`, then the open documents, unannounced. The address an
  entry dials is now part of what the seen store records, so a new or changed address is announced at startup and
  confirmed before a test launch. Entries that only connect, and `tcp` entries with both a command and a `connect`
  endpoint, are announced once after upgrading.

### Changed

- **A `tcp` listener must be on this machine** (#5465): `localhost`, `127.0.0.1` or `[::1]`, as a WebSocket
  listener already had to be. Whatever dials a listener first is taken as the language server, so a bind such as
  `tcp://0.0.0.0:6005` let any host on that network take the role. Such an entry is now refused with a
  configuration problem; a server on another machine is reached with `connect`.
