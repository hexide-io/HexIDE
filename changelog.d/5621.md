### Changed

- **File > Make, Make Project Group, Make with VB6 and Start with VB6 come from the Basic provider** (#5621).
  The provider registers what makes VB6's programs, and the four commands are unavailable for a project whose
  type has nothing registered to make it. A Make with VB6 whose compiler run fails to start is now reported as a
  failed build, where it used to end the command with only a log line. Where VB6 is found is unchanged: `VB6_EXE`, then its
  install folders.
