### Added
- **A publisher asks for a record with one command, and anyone can check the request** (#5321). The packer's
  `request-publisher` makes the publisher's key and a request signed with it, which proves the sender holds that key.
  `verify-request` checks a request's form, fields and signatures. Given the list of issued records, it also refuses an
  id, key or namespace another publisher already holds. A new key under an id you hold is a rotation, signed with the old
  key too. Both commands are in `hexide-pack`.
