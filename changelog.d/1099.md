### Added

- **The first MSFlexGrid model slice** (#1099): measured dimensions, cursor event order, selection text,
  TextMatrix/TextArray storage and Clip handling.

- **MSFlexGrid runtime binding** (#1099): a form holding a grid now runs, and code can set and read its
  dimensions, current cell, Text, TextMatrix and FormatString headings. Later grid members remain
  explicitly refused; drawing, input and saved-file fidelity follow separately.

- **MSFlexGrid programs can use selections and cell sizes** (#1099). RowSel, ColSel, FillStyle,
  Clip and TextArray are reachable from code, alongside ColWidth, RowHeight, ColAlignment,
  FixedAlignment reads and RowHeightMin assignments. Widths and heights round to pixels and
  invalid values retain the control's measured error numbers. Drawing and input follow separately.

- **MSFlexGrid programs can format cell fonts and alignment** (#1099). CellAlignment and
  CellFontName, CellFontSize, CellFontBold, CellFontItalic, CellFontUnderline and
  CellFontStrikeThrough follow FillStyle over the selection, including fixed cells, and read
  the current cell. Changing a cell font size keeps its row height. Drawing follows separately.

- **MSFlexGrid programs can add and remove text rows** (#1099). AddItem accepts tab-separated
  fields and an optional insertion index; RemoveItem keeps the control's measured fixed-row,
  out-of-range and last-row errors. Moving formatted rows remains refused.

- **MSFlexGrid programs can sort text rows** (#1099). Built-in sorts reproduce the measured quicksort,
  including unstable ties, and custom sorts await each Compare handler and its ByRef result before
  continuing. Fixed rows stay put and whole text rows move, including fixed columns. Sorting formatted
  rows or explicit row heights remains refused.

- **MSFlexGrid Sort has held-out oracle coverage** (#1099): the second recording pins 72 built-in
  orders, both directions of a sub-range sort, and every Compare in the 61-call and 155-call custom
  sorts.

- **MSFlexGrid mouse selection** (#1099): clicks select cells or whole headings, Shift extends the
  selection and right-click leaves the current cell in place. Mouse and cursor events follow the
  measured order, including double-click. Keyboard input, dragging, scrolling and drawing follow
  in later slices.

- **MSFlexGrid drawing and scrolling** (#1099): fixed headings, gridlines, aligned cell text and cell
  formatting now draw, with clipped or wrapped text, selection highlighting and a focus rectangle.
  Scrollbars appear when needed, headings stay fixed, and moving the current cell scrolls it into view.

- **MSFlexGrid keyboard navigation** (#1099): the measured arrows, Home/End, Ctrl+Home/End and page
  keys move the current cell, Shift+Down/Right extend the selection, and scrolling precedes the cell
  events. KeyUp follows the recorded keys individually. Enter and `a` raise key events without
  editing; Tab and Shift+Tab leave the grid. Unmeasured selection modes and keyboard edges remain refused.

- **MSFlexGrid free keyboard selections** (#1099): Shift+Up/Left, Home/End and page keys, plus
  Ctrl+Shift+Home/End, extend the selection while keeping its anchor. AllowBigSelection no longer
  blocks keyboard navigation when False. Row and column selection modes follow in a later slice.

- **MSFlexGrid row and column keyboard selections** (#1099): SelectionMode 1 and 2 preserve the
  code-set coordinate on the other axis, widen the selection on the first key and scroll only along
  the selected axis. Shift keys and plain keys retain the measured SelChange counts, with either
  AllowBigSelection setting. Unmeasured event-count edges remain refused.

- **MSFlexGrid saved forms retain their property blocks** (#1099): own properties, Boolean comments
  and the Font block stay in VB6's measured order through a save or a form caption edit. New toolbox
  grids write the measured bare block, including TabIndex. Carried settings remain unavailable for
  designer editing.

### Changed

- **MSFlexGrid integrates with the newer in-box controls** (#1099): the shared registry, runtime
  dispatch and form writer retain the controls added on main alongside the grid. The subsequent
  merge also preserves MSMask registration and both controls’ saved-corpus documentation.

### Fixed

- **MSFlexGrid cell underlines remain visible in short rows** (#1099), including with Windows fonts
  whose underline falls below the cell's text clip.
