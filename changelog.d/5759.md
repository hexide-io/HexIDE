### Fixed

- **Dragging a Line in the form designer no longer writes a wrong position when HexIDE can't run its container's scale**
  (#5759). The drag added a distance worked out in twips to X1, Y1, X2 and Y2, which are held in the container's own
  scale, such as a PictureBox whose ScaleMode is User, and a save kept the wrong values. The Line now stays where it
  is, as it already did when the scale rules failed. A Line in a scale HexIDE runs moves as before.
