### Added
- **The maintainer issues a publisher record from the approved request, with one command** (#5322). The packer's
  `issue-publisher` signs only a request whose SHA-256 is the one approved. Before signing, it runs every
  `verify-request` check again against the list of issued records, HexIDE's root and the revocation list, and the
  publisher id must be typed back. It writes the publisher's trust folder and a receipt, and adds the record to the
  public list. An id or key is never issued twice, and a replaced key stays recorded. A key replacement from a different
  GitHub account or address, or checked against an old revocation list, is left to a person.
