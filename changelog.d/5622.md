### Security

- **A project's names can no longer put Make's files outside their folder** (#5622). A form's or module's name, the
  project's `Name` and `ExeName32` were each joined onto a folder unchecked, so a project from elsewhere could make File >
  Make write a member's file above its staging folder, or Make Project Group, Make with VB6 and Start with VB6 write and
  start a program beside the project's folder. Each is now refused before anything is written, naming the field. A
  path in `ExeName32` is refused, though VB6 accepts one when building in place; `Path32` still names the folder.
