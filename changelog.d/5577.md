### Security
- **HexIDE checks the add-in revocation list every hour, not only at startup** (#5577). A session left open for days
  used to keep running an add-in revoked after it started. The check runs in the background while any add-in is
  installed, asks for the list only if it has changed, and stops when `revocationListUrl` is empty. When a newer list
  revokes a loaded add-in, HexIDE marks it Revoked and takes out its menus, commands, tool windows and language
  servers. It also stops sending it events. Its code stays loaded until HexIDE closes, so a notice names the add-in
  and offers to close HexIDE, with the usual prompts to save; the next start refuses it. Options → Add-Ins now says
  when the list was last checked, that the last check failed, or that checking is off.
