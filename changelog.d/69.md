### Fixed

- **View > Last Position now returns to the lines VB6 remembers** (#69): edited lines, Definition and
  Find origins, and the caret at run start. Its eight entries cycle, cross code windows and reopen closed
  ones.
- **Ctrl+Shift+F2 now goes to Last Position, as in VB6** (#69), and Cmd+Shift+F2 on macOS. Clear All
  Bookmarks no longer has a key. If you used it, remap it in Tools > Options > Environment > Keymap. It's
  still on the Edit > Bookmarks menu and the toolbar.
