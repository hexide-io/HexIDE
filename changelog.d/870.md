### Fixed

- **An in-box run shuts out the form designer while running or paused** (#870), so designer changes cannot
  move breakpoints away from the running program's line numbers. Designer tabs keep their undo history,
  selection and position for End; Toolbox, Properties and Form Layout return only if previously showing.
  Designer commands and automation refuse changes until the run ends; other View commands and their keys
  keep working when the focused designer leaves the dock. External debug sessions are unchanged.
