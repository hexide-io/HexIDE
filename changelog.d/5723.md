### Added

- **A project's format gives the class of a new form, designer root or menu item, and a template is told the format its project is made for** (#5723). `IProjectFileFormat.NewRootClass` and `NewMenuClass` answer for Add Form, Add User Control, Add Property Page and the Menu Editor, and `IAddinProjectTemplate.Create(name, format)` for a new project's own forms. VB6's format answers as before, so nothing a VB6 user sees changes, and the form designer no longer names the Basic provider's form and menu classes. A format that gives no class, or a class in another role, refuses the add with a message and changes nothing. Both format members default to null, and the template member to `Create(name)`, so an existing add-in still builds.
