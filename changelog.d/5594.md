### Changed

- **Add-ins put a control in the toolbox with `IHexIdeHost.RegisterToolboxItem`** (#5594). `RegisterComponent` registers the class, and no longer adds it to the toolbox by itself. Both are owned: only the host an add-in is given takes them, and a class whose type name another registration holds is refused, naming both owners. A form, menu or line class, a container, or a type name in VB6's own `VB.` namespace needs a grant from HexIDE, which today only the Basic provider holds. The provider registers its own Form, controls and toolbox items this way, and the toolbox looks as it did.
