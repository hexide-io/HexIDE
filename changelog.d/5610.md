### Changed

- **A component class can describe its members to the Object Browser through Core's `IComponentMemberTable`** (#5610). It's optional, and it names the members a control has in a given library, as Common Controls 5.0 and 6.0 differ. A class without one is still described by its properties and events. What the Object Browser lists for HexIDE's own controls doesn't change.
- **The Object Browser lists a control library from the libraries registered with the IDE** (#5610). `IControlLibrary` gains `Version`, and a library can list the classes it declares beyond its controls through the optional `IControlLibraryContents`. A library without it is listed by the controls it registered.
