### Changed

- **VB6's project files are read and written by the Basic provider** (#5625, part of #3411). The provider registers VB6's project type through the same host call any add-in uses, and HexIDE's grant gives that type VB6's identity, so `.vbp` and `.vbg` projects open, save, run and make as before, and `--no-vb6` still leaves them out. No other add-in can claim `.vbp`, `.vbg` or that identity, whatever order things load in.
