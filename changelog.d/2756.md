### Fixed

- **Saving a shared module, class or form preserves each project's edit** (#2756, round 1). Group saves write one changed copy per file and let you choose when several copies changed. After saving, the IDE offers to update the other projects' copies, asking separately before discarding unsaved changes. A per-copy disk check asks before a stale copy overwrites a newer file; unattended saves refuse when consent is needed. Closing or reloading a project stops if a selected shared copy remains unsaved. Dialogs are translated into every shipped language.
