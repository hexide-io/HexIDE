### Added
- **`hexide-pack` asks for whatever a packer command leaves out** (#5555). Run `hexide-pack pack`, or just
  `hexide-pack` to pick a command, and it asks for each missing option, checking each answer as you give it. It then
  shows the whole command and asks before it runs. It asks only on a terminal outside CI, and `--no-input` turns
  that off; anywhere else a missing option fails at once and the message says why. It won't write private keys
  inside a git clone. It runs the packer's own commands, so nothing signs differently.
