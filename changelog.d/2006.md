### Added

- **Named panel layouts in the Window menu** (#2006). Save the current arrangement under a name, switch,
  rename or delete saved layouts, or use Full Editor to give documents the whole frame. Layouts restore
  add-in windows through the same `addin:<id>` keys as the current layout; unavailable windows are deferred and reported.

### Fixed

- **Window → Panel Layouts opens its submenu** (#2006). Saved layouts and the Save, Rename and Delete
  commands are reachable on the first opening. Saved-layout entries expose their names to accessibility tools.
  Named layouts share the current layout’s add-in keys, including deferred restoration into document tabs.
