### Security

- **The add-in revocation list can name a signing key** (#5315). A stolen publisher key can now be revoked on its own,
  leaving the record issued for the publisher's new key standing. A revoked first-party key stops the add-ins signed
  with it. A revoked marketplace intermediate key stops the add-ins under it, except first-party ones. Earlier
  versions ignore key revocations and still apply the rest of the list. The add-in packer won't issue a revoked key,
  leaves a key replacement away from one to the maintainer, and won't sign a revocation list HexIDE would ignore.
