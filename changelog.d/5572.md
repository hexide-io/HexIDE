### Security
- **A revoked first-party add-in build is now refused on a default install** (#5572). HexIDE fetched the published
  revocation list at startup only when a third-party add-in was installed, so with only the bundled add-ins it never
  saw a revocation of one of them until HexIDE itself was updated. It now fetches whenever any add-in is installed,
  with the same three-second limit, and starts normally if hexide.io can't be reached.
