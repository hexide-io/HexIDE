### Security

- **A package can no longer take HexIDE's own add-in ids** (#5597). A package whose manifest id is `hexide.` or under it, in any case, loads only if HexIDE's first-party key signed it; otherwise it's listed with an error naming the reserved id. What an add-in contributed is now kept by owner, so disabling or revoking a package that names the Basic provider's id no longer takes out the provider's themes, text or designer drawer.
