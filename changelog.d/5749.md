### Added

- **A control's class can tell the form designer which library the control is in** (#5749). `IDesignerLibraryControl` gives the library a control is in, and records the library whose toolbox entry it was placed from. The Basic provider's in-box controls answer through it, so the form designer no longer names their class, and each form still declares the library VB6's designer writes for it. The designer declares only a library the IDE has registered as offering the control's class, since the line goes into the user's form. A class that throws is logged, and its control is placed as before.
