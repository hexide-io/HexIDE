### Changed

- **A language's editing helpers register per language, through the host an add-in is given** (#5403). The code window's `#If` greying and bracket colouring, and the declarations the Object Browser and the Watch dialog list without a language server, come from the helpers the Basic provider registers for `vb6` and `twinbasic`. Nothing you see changes. A language with none registered gets none of the three, as a plain-text file has. A helper that throws is logged and answers nothing for that call, so it can't take the code window down.
