### Fixed

- **An error raised deep in a recursion reaches its handler in linear time** (#3247). Each procedure threw the
  error on with the whole .NET stack trace gathered below it, so an error raised N calls deep cost N² to surface:
  18 s at 1,200 calls in a Debug build. Each procedure now throws it on with its own trace only, which takes 0.9 s
  at the same depth. Err, Erl and every On Error handler see the error as before.
