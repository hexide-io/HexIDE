### Security
- **Running the release workflow again for a published release is refused before anything is built** (#5424). It used
  to replace that release's downloads, the signed add-ins and the installer among them, with a build of whatever commit
  the new run was on, under the old tag. A draft release can still be re-run until it is published. The release job
  checks again just before uploading, in case the draft was published while the run built.
