### Added

- **Renaming a control can create a control array** (#1397). The Properties window asks before giving the
  original Index 0 and the renamed control Index 1; No leaves both unchanged, and one Undo restores both.
  An unindexed control joins an existing array of its type without a question, taking one more than its highest Index.
  `set_control_property` explains how to create the array by setting the original’s Index to 0 first.
