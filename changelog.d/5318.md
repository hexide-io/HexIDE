### Added
- **`pack --key <file>` names the publisher key wherever it is kept** (#5318). The trust folder then needs only the four
  public chain files, so a third-party publisher no longer stores their key as `firstparty.key`. `pack` checks a key
  given this way against the publisher record, as it does the trust folder's, and refuses a key named among the files
  to bundle. `hexide-pack pack` asks for it after the trust folder, and Enter keeps using `firstparty.key` there.
