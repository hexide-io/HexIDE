### Added

- **`IHexIdeHost.RegisterResources` lets an add-in HexIDE grants it to add a resource dictionary** (#5396). It's from the add-in's own
  assembly and deny by default: only keys in the families the owner's grant names, and never a `Str.*` key, a key the IDE or another
  add-in holds, or a type the add-in doesn't declare. Every key is checked before anything merges, and one refused key refuses the
  dictionary. The Basic provider's control themes now arrive this way, through the entry point phase 3 of the HexIDE.Basic move will
  load as a bundled add-in.
