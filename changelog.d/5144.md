### Added

- **Rename and delete twinBASIC modules, and add source folders** in a `.twinproj` project's tree (#5144).
  Each command saves immediately through the verified, recoverable container writer; Delete asks first.
  Unsaved source edits and external disk changes refuse the operation. Open tabs follow a rename or close
  after deletion. Names must be unique ASCII identifiers, excluding reserved device names. Forms, folder
  rename/delete, module addition and Settings edits remain refused until measured against the twinBASIC IDE.
