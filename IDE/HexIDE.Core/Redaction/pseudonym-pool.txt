# The pseudonym pool.
#
# A fixed sequence of harmless words. Nothing here is chosen for meaning: a pseudonym's whole job is to be
# stable within a session, obviously not a real name, and forgettable. Lines beginning with '#' and blank
# lines are ignored, so the thematic grouping below is for whoever has to read this file rather than for
# the code, which sees one flat list.
#
# RULES, ASSERTED BY PseudonymPoolTests. Every word: lowercase ASCII letters only, at least three
# characters, no hyphen (the hyphen joins words when the pool runs out), and unique across the whole file.
# The COUNT is pinned too, because the pool size is the base of the numbering scheme — changing it changes
# every pseudonym past the first thousand, and a silently resized pool would make two captures from two
# builds disagree about the same path for no visible reason.
#
# The order is fixed but arbitrary. Nothing reads the pool in order: each session draws a fresh permutation
# from a cryptographic seed and loses it on exit, so a pseudonym cannot be carried from one session to the
# next even by somebody who has this file.
